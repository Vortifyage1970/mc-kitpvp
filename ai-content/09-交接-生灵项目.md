## 三、1.20.1 的硬规则（违反任何一条 = 整段坏掉）

1. **一行坏掉，整个 `.mcfunction` 不注册**，报错只在 `logs/latest.log` 里，游戏内表现为"未知的函数"。查错：搜 `Failed to load function` / `Whilst parsing command on line N`。
2. 没有 `return`、没有 `/tick` 命令、没有 `/random`、没有宏、没有带参函数。
3. **`scores={kitpvp.X=..0}` 在分数不存在时不匹配任何实体**。凡是靠分数当门槛，summon 时必须埋初值。
4. **`kill` 只是标记丢弃，实体要到当前刻结束才真正移除**。所以"先 kill 再 summon 同一个写死 UUID"必然失败——`addFreshEntity` 发现 UUID 被占会**静默拒绝**（不报错、不生成）。跨帧（`schedule 1t`）也一样，`kill` 与"下一帧"经常正撞。
5. **`schedule` 出来的函数没有位置上下文**，`~ ~ ~` 相对的是执行者默认坐标，不是召唤者。
6. **`sort=nearest` 和 `sort=furthest` 在同一批选择集里会互相打架**（选出同一个实体）。
7. 选择器的 `dx/dy/dz` **只收 double，不收范围**（`dy=6..` 非法，整个文件不注册）；`distance`/`scores`/`x_rotation` 才能写范围。
8. 物品用**旧 NBT**：`Enchantments:[{id:"...",lvl:2}]`、`display.Name`、`Unbreakable:1b`、`Damage`。`run_command` 的 value 必须带前导 `/`。
9. **`Leash` 的值是复合标签** `{UUID:[I;a,b,c,d]}`，裸 int 数组会被静默丢弃。1.20.1 **没有 `/leash` 命令**，所以拴绳只能靠写死 UUID 指名道姓。
10. **同一函数里同时召出的兄弟实体不在 UUID 索引里** —— 被拴方必须另起一帧（`schedule 1t`）并锚在母体身上。
11. 原版生物持绳**超过约 10 格就脱绳**，并掉一个 `minecraft:lead` 物品。
12. `effect give ... infinite <amplifier>` 比写 NBT `ActiveEffects` 可靠。
13. 原版**生物持绳 >10 格必脱绳**、**着火实体碰细雪会拆掉方块**、**原版 `Mob.isSunBurnTick()` 在头槽非空时不烧**——这些都是踩过的坑。

## 四、工作流（每次改动严格照做）

```powershell
Set-Location 'E:\Projects\mc-kitpvp'
# 1) 改文件：src\data\kitpvp\functions\...
# 2) 体检
powershell -NoProfile -ExecutionPolicy Bypass -File 'tools\lint_functions.ps1'
#    动了随机池再跑
powershell -NoProfile -ExecutionPolicy Bypass -File 'tools\check_pool.ps1'
# 3) 部署到两个存档
powershell -NoProfile -ExecutionPolicy Bypass -File 'tools\deploy.ps1' -SavePath 'E:\Games\mc启动器\PCL 正式版 2.10.3\.minecraft\versions\1.20.1-Forge_47.4.23\saves\职业战争'
powershell -NoProfile -ExecutionPolicy Bypass -File 'tools\deploy.ps1' -SavePath 'E:\Games\mc启动器\PCL 正式版 2.10.3\.minecraft\versions\1.20.1-Forge_47.4.23\saves\新的世界'
# 4) 提交（英文简短 commit message）
git add -A; git commit -m "..."
```

- **部署不会自动 `/reload`**。必须让用户在游戏里 `/reload`（或退出重进世界），否则他看到的还是旧行为——这条每次都要说。
- 真实使用的存档是 **`职业战争`**（`新的世界` 是备用）。
- `tools\deploy.ps1` **必须是 UTF-8 带 BOM**（PS 5.1 按 ANSI 读会报"缺少右 }"），它同步后会删掉存档里的多余文件、并把同名 zip 改成 `.off`。
- **`tools/*.ps1` 输出是 GBK 控制台**，中文可能显示成乱码，不影响判断。
- `ai-content/` 和 `tools/` 都在 `.gitignore:21-22`，只在本地，不进仓库。
- 推远端常需要代理（`127.0.0.1:7897`）+ `-c http.version=HTTP/1.1`。**目前有 5 个 commit 没有推送**。

| `functions/tick.mcfunction` | 全局每刻；`355` 行是飞行器 tick 调用（其它生灵也在这里挂） |

1. `summon/earth_xxx.mcfunction`（召唤 + 埋初值 + 补队伍/归属）
2. `skill/earth/xxx_*.mcfunction`（逻辑），在 `tick.mcfunction` 挂上
3. `random.mcfunction`：`#pool_size` +1，加一行 `matches N`
4. `kit/info/earth.mcfunction` 卡片
5. `check_pool.ps1` 白名单（若有子部件函数）
6. `08-地球生灵档案.md` 写一节
