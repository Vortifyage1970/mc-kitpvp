十、tag / objective 生命周期约定

1. 每新增一个 tag，都必须回答：这个 tag 该不该进 `util/clear_player` 的清理清单？
   - 会话性 tag（`joined`、`in_lobby`）**不清**。
   - 游戏性 tag（其余绝大多数）**要清**。
2. 每新增一个 objective，必须在 `load.mcfunction` 里统一创建，
   并在 `03-project-spec.md` 第六节的登记表里补一行。
3. 每新增一个 `*_last` 快照变量，必须在 `load` / `player/join` / `util/clear_player`
   三处初始化（见第七节）。
4. 已建但从未被读写的 objective（`map`、`timer`、`item`、`cd2`）
   属于**预留**：不要删，也不要假设它们有值。

现有 `util/clear_player.mcfunction` 清 tile 清单：
`selected / invincible / sudden_death / spectator / respawn_pending /
death_immune / keep_inventory / skill_ready / skill_consume /
shield_held / assassin_hidden / ready / ready_pending`

现有 `util/clear_player.mcfunction` 刻意不清清单：
`joined / in_lobby`
